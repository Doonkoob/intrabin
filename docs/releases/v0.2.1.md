# Intrabin v0.2.1

## A more consistent panel
- Grouped navigation separates monitoring, operations and workspace management. A contextual header and account card make the current page and workspace easier to identify.
- Refined dashboard metrics, typography, spacing, buttons, forms, tables, empty states and dialogs use one visual system throughout the panel.
- Sign-in and setup screens use a new responsive layout. Light and dark themes support English and Persian, including right-to-left navigation and mobile layouts.
- The mobile navigation traps keyboard focus, closes with Escape or a backdrop click, restores focus on close, and closes when switching to a desktop viewport.

## Clearer update status
- A completed check with no newer release displays **No update available** (or its Persian translation).
- Repositories without a stable release or version tag produce a successful empty check instead of an update-check failure. Stale cached release information is cleared.
- Genuine connection, permission and installation failures remain visible, and an installation in progress is never labeled as having no update available.

## Updating
Use **Settings → Software updates → Check now** on the leader, then install v0.2.1. Nodes with the v0.2.0 update agent continue to build and update containers sequentially, with progress tracking and automatic cluster rollout. This release does not change database schemas or the host update scripts.
