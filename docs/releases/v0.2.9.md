# Intrabin v0.2.9

Includes the leader-managed unique node names introduced in v0.2.8, with a compatibility fix for
custom names that also resemble UUIDs (for example 32 hexadecimal characters). Result filters
now resolve the assigned name correctly, while historical UUID filters remain usable.

On the leader, open **Cluster / Nodes → Rename node**. Names appear as the node label and public
ID, replicate to members, and survive restarts. Internal UUIDs, certificates, assignments and
history stay intact. Existing clusters do not need to be initialized or joined again.
