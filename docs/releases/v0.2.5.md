# Intrabin v0.2.5

The application and Action Runner source builds now use `https://goproxy.cn` by default instead
of the standard Go module proxy. This applies to direct Docker builds and Compose builds,
including existing installations whose `GOPROXY_URL` setting is empty.

Set `GOPROXY_URL` in `/opt/intrabin/.env` to override it. Go checksum verification remains enabled.
Published-image updates continue to work without downloading Go dependencies on the server.
