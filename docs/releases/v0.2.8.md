# Intrabin v0.2.8

Choose a unique name for each node from the leader's **Cluster / Nodes → Rename node** action.

- Custom names become the node's display label and public `node_key` across the panel, monitoring
  charts, probe selection and cluster update progress.
- Names are unique across the cluster, ignoring letter case. Conflicting concurrent renames are
  rejected. Use 1–63 letters, digits, dots, underscores or hyphens, starting and ending with a
  letter or digit (for example `tehran-01`).
- Node management API paths, monitor `node_ids` and result `node_id` filters accept these names.
  Existing UUID references continue to work.
- Names are replicated to members and retained through restarts and upgrades. Heartbeats and
  host-name changes cannot overwrite a custom name. **Use address** restores the default label.
- Internal UUIDs, certificates, monitoring history, saved assignments and membership remain intact.

This applies to existing clusters after upgrading. No Init or Join is needed. Previous releases
continue to store the replicated name setting during a rolling upgrade; their UI adopts it when
upgraded. Only the active leader accepts rename requests.
