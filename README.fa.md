# Intrabin

**قطعی را از چند نقطه ببینید؛ علت را پیدا کنید و از یک پنل اقدام کنید.**

اینترابین پایش سرویس، پیگیری رخداد و خودکارسازی بازیابی را روی سرور خودتان فراهم می‌کند.
با یک سرور شروع کنید و برای پایش از شهرها یا شبکه‌های دیگر، نود اضافه کنید.

[English](README.md) · [نسخه‌ها و تغییرات](CHANGELOG.md)

## چه نیازی را برطرف می‌کند؟

| نیاز شما | قابلیت اینترابین |
| --- | --- |
| سرویس اینجا باز می‌شود، جای دیگر نه | نتیجه و نمودار تأخیر به تفکیک نود |
| معلوم نیست مشکل از CDN است یا سرور اصلی | پایش مستقیم مبدأ و تفکیک خطاهای DNS، TLS، HTTP و زمان پاسخ |
| خطاهای لحظه‌ای باعث رخدادهای اضافی می‌شوند | تأیید چندنودی، آستانهٔ خطا و بازهٔ نگهداری |
| واکنش به قطعی هر بار دستی انجام می‌شود | گردش‌کار با اسکریپت، وب‌هوک و تغییر DNS |
| باید ترافیک به سایت پشتیبان منتقل شود | انتقال DNS با بررسی سلامت و فاصلهٔ زمانی بین انتقال‌ها |
| مدیریت و آپدیت چند سرور زمان‌بر است | پنل مشترک، آپدیت ترتیبی نودها و نمایش پیشرفت |

پایش HTTP/HTTPS، TCP، DNS و انقضای گواهی TLS؛ تاریخچهٔ دسترس‌پذیری و رخدادها؛
اتصال به Cloudflare و ابرآروان؛ نقش‌های کاربری؛ رابط فارسی و انگلیسی با تم روشن و تیره.

داده‌ها روی زیرساخت خودتان می‌مانند. در کلاستر، رهبر جایگزین خودکار انتخاب می‌شود؛
بدون حد نصاب، تغییر تنظیمات و عملیات بازیابی متوقف می‌شوند.
انتقال DNS جایگزین تکثیر دادهٔ برنامه نیست؛ بازگشت به سایت اصلی دستی است.

## نصب

روی Ubuntu 20.04، 22.04 یا 24.04 با کاربر root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Doonkoob/intrabin/main/scripts/install.sh)
```

نصب‌کننده Docker را آماده می‌کند، در صورت انتخاب دامنه HTTPS را راه می‌اندازد و آدرس پنل
و اطلاعات ورود را نمایش می‌دهد. بدون دامنه، پنل روی HTTP و پورت 8080 است.
برای دریافت ایمیج آماده، گزینهٔ `--release vX.Y.Z` را با شمارهٔ یک نسخهٔ منتشرشده وارد کنید.

پس از ورود، یک مانیتور بسازید و آن را تست کنید. از بخش «کلاستر / نودها» سرورهای دیگر را
اضافه کنید. برای مدیریت سرور دستور `intrabin` و برای آپدیت، بخش به‌روزرسانی در تنظیمات را باز کنید.
